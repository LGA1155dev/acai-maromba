## 📖 Sobre o projeto

O **Açaí Maromba** é um projeto de desenvolvimento web criado para representar uma marca com identidade voltada ao universo fitness, combinando açaí, alimentação, energia e estilo de vida.

A proposta é desenvolver uma experiência visual que transmita personalidade, utilizando elementos gráficos, tipografia marcante e uma interface que conecte o universo do açaí com o público que busca uma alimentação associada ao treino e ao bem-estar.

O projeto funciona como uma página web de apresentação de marca, explorando recursos de HTML e CSS para construir uma interface moderna e visualmente atrativa.

## 🚀 Como executar o projeto localmente

Você pode executar o projeto diretamente no navegador ou utilizar um servidor local.

### 1️⃣ Clone o repositório

```bash
git clone https://github.com/LGA1155dev/acai-maromba.git
```

### 2️⃣ Acesse a pasta do projeto

```bash
cd acai-maromba
```

### 3️⃣ Execute o projeto

Como o projeto utiliza HTML e CSS, você pode abrir o arquivo `index.html` diretamente no navegador.

Ou, caso prefira utilizar um servidor local com Python:

```bash
python3 -m http.server 8000
```

Depois, acesse:

```text
http://localhost:8000
```
